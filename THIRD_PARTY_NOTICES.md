# Third-party data and software

This repository contains original code but no third-party imagery or labels. Users are
responsible for complying with each source's current terms.

- Copernicus Sentinel-1 GRD: European Union/ESA Copernicus data.
- Dynamic World: Google and World Resources Institute.
- AlphaEarth Foundations annual embeddings: Google, distributed through Source Cooperative.
- SWORD v16: SWOT River Database authors and distributors.
- GSWD PlanetScope-based reference annotations: the dataset authors and source imagery provider.
- OPERA DSWx-S1: NASA/JPL OPERA project and NASA PO.DAAC.
- ImageNet-pretrained ResNet-34 weights: torchvision/PyTorch upstream terms.

The repository's Apache-2.0 license does not supersede any third-party license,
attribution requirement, acceptable-use policy, or imagery redistribution restriction.
